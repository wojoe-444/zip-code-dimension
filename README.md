# ZIP code dimension

A sample of five-digit U.S. ZIP codes for use as a starting point for a geographic dimension. The table contains the two standard ZIP codes with the largest reported population in each state, the District of Columbia, and Puerto Rico, as recorded in the source dataset. It is not a complete ZIP code directory.

ZIP codes and county FIPS codes are identifiers: store them as text to preserve leading zeroes. County is the main county by land area; coordinates are approximate ZIP code centers. Population is the 2020–2024 American Community Survey five-year estimate. The dataset was updated November 2, 2026. Confirm postal addresses with USPS.
